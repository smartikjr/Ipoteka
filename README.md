# 🏦 мини-Домклик — ИИ в ипотечном кредитовании

Интерактивный прототип к выпускной квалификационной работе
**«Возможности и риски использования искусственного интеллекта в ипотечном
кредитовании в российских коммерческих банках (на примере ПАО Сбербанк)»**.

Прототип в действии демонстрирует четыре технологических узла ипотечного
ИИ-конвейера (как у сервиса «Домклик») и реализует рекомендации третьей главы
работы: интерпретируемость (SHAP), тестирование на справедливость (fairness),
мониторинг моделей (PSI) и карту рисков.

> ⚠️ **Важно.** Все данные — **синтетические** (сгенерированы программно) и
> калиброваны под параметры из ВКР. Это демонстрация *методологии*, а не
> реальные данные банка (доступ к ним невозможен и не требуется).

---

## ⚡ Быстрый запуск

Нужен только установленный **Python 3.10+**.

```bash
# 1. Создать виртуальное окружение
python3 -m venv .venv

# 2. Активировать его
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить приложение
streamlit run app.py
```

Откроется браузер по адресу <http://localhost:8501>.
**При первом запуске** приложение само сгенерирует данные и обучит модели
(≈ 1–2 минуты, разовая операция) — отдельных команд не требуется.

## 🧭 Что внутри (7 разделов)

| Раздел | Что показывает | Связь с ВКР |
|---|---|---|
| 🏠 **Обзор** | Ключевые цифры и архитектура ИИ-конвейера | Введение, разделы 2.1–2.2 |
| 📝 **Скоринг и объяснение (SHAP)** | Решение по заявке + PD + объяснение каждого фактора | **Рекомендация 3** (интерпретируемость) |
| 🏢 **Оценка недвижимости (AVM)** | Двухступенчатая модель CatBoost → LightGBM | Раздел 2.2 (AVM «Домклик») |
| ⚖️ **Справедливость моделей** | Demographic Parity, Equal Opportunity, правило 4/5 | **Рекомендация 2** (предвзятость) |
| 📊 **Мониторинг моделей (MOC)** | PSI и деградация модели при макрошоке | **Рекомендации 1 и 4** |
| 🗺️ **Карта рисков** | 6 групп рисков по осям вероятность × влияние | Раздел 3.2, Таблица 5, Рисунок 4 |
| 📈 **Эффекты внедрения ИИ** | Сопоставление «до / после» | Раздел 3.1, Таблица 4 |

## 📊 Качество моделей (совпадает с ориентирами ВКР)

| Модель | Метрика | Значение | Ориентир ВКР |
|---|---|---|---|
| Кредитный скоринг (LightGBM) | Gini | **≈ 0.78** | 0.75–0.80 |
| | AUC / KS | ≈ 0.89 / 0.63 | — |
| AVM (CatBoost → LightGBM) | MAPE | **≈ 4.3 %** | 4–5 % |
| | R² | ≈ 0.99 | — |

> Защищённые признаки (пол, возрастная группа) **в модель скоринга не подаются**
> и используются только для проверки справедливости.

## 🗂️ Структура проекта

```
.
├── app.py                  # Streamlit-приложение (7 разделов)
├── requirements.txt        # Зависимости
├── src/
│   ├── config.py           # Цифры из ВКР, признаки, справочники
│   ├── data_gen.py         # Генерация синтетических данных
│   ├── train.py            # Обучение скоринга и AVM
│   ├── scoring.py          # Инференс скоринга, отложенная выборка
│   ├── avm.py              # Инференс двухступенчатой AVM
│   ├── explain.py          # Объяснения SHAP (Рекомендация 3)
│   ├── fairness.py         # Метрики справедливости (Рекомендация 2)
│   ├── monitoring.py       # PSI и сценарий шока (Рекомендации 1, 4)
│   ├── risk_map.py         # Карта рисков (Таблица 5 / Рисунок 4)
│   └── bootstrap.py        # Авто-подготовка данных/моделей
├── scripts/
│   └── make_figures.py     # Генерация PNG-графиков для презентации
├── docs/
│   ├── figures/            # 8 готовых графиков для слайдов
│   └── ЗАЩИТА_тезисы.md    # Тезисы для защиты (что говорить)
├── data/                   # Данные (создаются автоматически)
└── models/                 # Модели (создаются автоматически)
```

## 📸 Скриншоты для презентации

В каталоге `docs/figures/` уже лежат **8 готовых графиков** (PNG, высокое
разрешение) для вставки в слайды: SHAP-объяснение, двухступенчатая AVM,
fairness, мониторинг PSI, карта рисков, эффекты ИИ, ROC-кривая, точность AVM.

Скриншоты **самого интерфейса** проще всего сделать на своём компьютере:
запустите `streamlit run app.py`, пройдите по разделам и нажмите `PrtScr`
(Windows) или `Cmd+Shift+4` (macOS).
