# 🇷🇺 Как включить «настоящего» ИИ-бота через GigaChat (Сбербанк)

GigaChat — российская языковая модель Сбербанка, **бесплатная для физических лиц**,
работает из России без VPN и идеально соответствует теме вашей ВКР (как в «Домклик»).
Это лучший вариант, если Groq/OpenAI недоступны из вашей страны.

> Для регистрации нужен **Сбер ID** (аккаунт Сбербанка / российский номер телефона).

---

## Шаг 1. Получите ключ авторизации GigaChat
1. Откройте **https://developers.sber.ru/** и войдите через **Сбер ID**.
2. Перейдите в раздел **GigaChat API** → **Получить доступ / Создать проект**.
3. Выберите тариф **«Для физических лиц»** (бесплатный, scope `GIGACHAT_API_PERS`)
   и примите условия.
4. В проекте найдите **«Авторизационные данные»** (Authorization key) — это длинная
   строка в кодировке Base64. **Скопируйте её целиком.**

## Шаг 2. Добавьте ключ в настройки приложения (Streamlit Cloud)
1. В приложении: **Manage app → ⋮ → Settings → Secrets**.
2. Вставьте строку (подставьте свой ключ):

   ```toml
   GIGACHAT_CREDENTIALS = "вставьте-сюда-авторизационные-данные"
   ```
   *(при необходимости можно добавить `GIGACHAT_SCOPE = "GIGACHAT_API_PERS"` и
   `LLM_MODEL = "GigaChat"` — но это значения по умолчанию)*
3. Нажмите **Save**. Приложение перезапустится (~1–2 минуты).

## Шаг 3. Проверьте
В разделе **🤖 ИИ-консультант** вверху появится зелёная плашка
**«🟢 Подключена языковая модель (LLM)»**, модель: GigaChat. Задайте свободный
вопрос — ответит GigaChat.

---

## Частые вопросы

**Это бесплатно?** Да, для физических лиц GigaChat даёт бесплатный объём токенов,
которого с запасом хватит для демонстрации на защите.

**Если ключ не сработает?** Консультант автоматически вернётся во встроенный режим
и продолжит отвечать по базе знаний — приложение не «упадёт».

**Почему именно GigaChat для защиты?** Это прямая иллюстрация вашей работы:
в ВКР показано, что Сбербанк применяет GigaChat в клиентских интерфейсах «Домклик».
Можете прямо сказать комиссии: *«ИИ-консультант работает на GigaChat — той же модели,
что Сбербанк использует в Домклик»*.

**А если я за границей / хочу другой сервис?** Тогда подойдёт Groq (см.
`docs/НАСТРОЙКА_ИИ_Groq.md`) или любой OpenAI-совместимый API.
