# 🤖 Как включить «настоящего» ИИ-бота (бесплатно, через Groq)

По умолчанию ИИ-консультант работает во встроенном режиме (без ключа). Чтобы он
стал полноценным диалоговым ИИ на базе языковой модели — подключите бесплатный
ключ **Groq** (быстрый OpenAI-совместимый сервис, без привязки карты).

Это занимает ~3 минуты и делается один раз.

---

## Шаг 1. Получите бесплатный ключ Groq
1. Откройте **https://console.groq.com** и зарегистрируйтесь (через Google или почту —
   карта не нужна).
2. Слева выберите **API Keys** → **Create API Key** → придумайте название → **Submit**.
3. **Скопируйте ключ** (начинается с `gsk_...`). Он показывается один раз — сохраните его.

## Шаг 2. Добавьте ключ в настройки приложения (Streamlit Cloud)
1. Откройте ваше приложение и нажмите справа внизу **«Manage app»**.
2. Меню **⋮ → Settings → Secrets**.
3. Вставьте в поле секретов эти три строки (замените ключ на свой):

   ```toml
   LLM_API_KEY = "gsk_ВАШ_КЛЮЧ"
   LLM_BASE_URL = "https://api.groq.com/openai/v1"
   LLM_MODEL = "llama-3.3-70b-versatile"
   ```
4. Нажмите **Save**. Приложение перезапустится автоматически (~1–2 минуты).

## Шаг 3. Проверьте
Откройте раздел **🤖 ИИ-консультант**. Вверху должна появиться зелёная плашка
**«🟢 Подключена языковая модель (LLM)»**. Задайте свободный вопрос, например:
*«Объясни простыми словами, чем семейная ипотека лучше рыночной»* — ответит
языковая модель.

---

## Частые вопросы

**Это точно бесплатно?**
Да, у Groq щедрый бесплатный лимит, которого с запасом хватит для демонстрации
на защите. Карта не требуется.

**Что, если ключ не сработает?**
Ничего страшного: при любой ошибке консультант автоматически вернётся во
встроенный режим и продолжит отвечать по базе знаний. Приложение не «упадёт».

**Можно ли другую модель/сервис?**
Да. Поле `LLM_BASE_URL` поддерживает любой OpenAI-совместимый API. Например,
OpenAI: `https://api.openai.com/v1` и `LLM_MODEL = "gpt-4o-mini"` (платно).

**Безопасно ли это?**
Ключ хранится в защищённых секретах Streamlit и не попадает в код или репозиторий.
Для защиты можно подключить ключ перед выступлением и удалить после.
